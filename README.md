# ASCII Table Generator

A small ASCII table generator written in C.

A practice project to explore C by recreating a table generator I previously built with JavaScript.

**Just wanna write code. That's it.**

## Example

```text
+----------+--------+
| name     | points |
+----------+--------+
| Anderson | 18420  |
| Bennett  | 7635   |
| Crawford | 42190  |
+----------+--------+
```
